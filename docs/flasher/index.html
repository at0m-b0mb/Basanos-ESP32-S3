Basanos

the touchstone for wireless defences

A wireless assessment instrument for the ESP32-S3. Every other tool of its class answers “can I knock this over?”. Basanos answers “would we have seen it?” — it emits a known signal at a network you are authorised to test, watches for your detection equipment to react, and scores it: caught or missed, how many seconds late, at what confidence.

Install

Connect the board over USB-C and click. Chrome or Edge on a desktop — Web Serial is not available in Safari or Firefox.

This browser has no Web Serial. Open the page in Chrome or Edge on a desktop, or flash the release asset with esptool. Web Serial needs a secure origin. Use the https:// address.

Authorised testing only

Transmitting deauthentication or disassociation frames at a network you do not own or have written permission to test is a criminal offence in most jurisdictions. This firmware makes that harder to do by accident and does nothing whatever to make it lawful. If you cannot name the authorisation, the device will not arm — and that is not a formality you can switch off.

What makes it an instrument

It is never unfair to a detector

A run is not called MISSED until the grace window after the emission has fully elapsed. Scoring the instant a burst stopped would slander a detector that alarms two seconds later.

It refuses to score what it did not send

If the radio rejects the frames, the run is discarded rather than recorded as a miss. Blaming the detector for the transmitter’s failure is the one output this device must never produce.

Manual targeting, always

One network, chosen by hand. Then the access point alone, a ticked set of clients, or the whole cell — scoped by BSSID, so no other network is touched.

Nothing transmits unauthorised

An engagement needs a label naming the authorisation and expires on a timer. It is re-checked before every frame, so a lapse stops a burst that is already in flight.

It keeps no key material

The passphrase audit runs on the device and wipes the handshake when it finishes. The finding is the output; the artefact is not.

It says what it cannot know

An unmeasured channel is reported as unmeasured, not quiet. A tracker is “looks like Find My”, never “is an AirTag”.

Hardware

Waveshare ESP32-S3-Touch-LCD-1.54 — 240×240 touch panel, 16 MB flash, 8 MB octal PSRAM, Li-ion, microSD. 2.4 GHz only; there is no 5 GHz radio on this part, so a 5 GHz network is invisible to it.
